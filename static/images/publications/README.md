# Adding Publication Images

To add Figure 1 from each paper to your website, follow these steps:

## Instructions

1. **Download Figure 1** from each paper using the links below
2. **Save the image** with the specified filename
3. **Place the file** in `static/images/publications/`
4. The website will automatically display the images

## Images to Download

## Quick Steps

1. Open each paper link
2. Find Figure 1
3. Right-click the figure image
4. Select "Save Image As..."
5. Save with the exact filename listed above
6. Place all images in `static/images/publications/`

The publication pages are already configured to display these images!
